# Дальнейшее развитие «Законки»

Обновлено: 21 октября 2026. Рабочая версия: 2.0 alpha.

Пользователь одобрил семь первоначальных предложений, затем следующие шесть
и техническое направление: сохранение проекта в GitHub и замену старого кода.
Разработка продолжится позже; этот документ фиксирует план,
а не объявляет функции готовыми. Обыск, досмотр и новые РП-сценарии исключены.

## Согласовано пользователем

### 1. Два режима оверлея — первый приоритет

- Компактная полоска с выбранной статьёй и развёрнутая панель.
- Переключение одной клавишей без потери выбранной статьи и расчёта.
- Положение и размеры сохраняются отдельно для каждого режима.
- Проверить возврат управления игре и работу на Windows рядом с игрой.

### 2. Настройка внешнего вида

- Размер текста, прозрачность и масштаб интерфейса.
- Несколько готовых вариантов с быстрым применением и возвратом настроек.
- Настройка текста и прозрачности уже есть в alpha; её требуется развить,
  добавить масштаб и готовые варианты, а не создавать заново.

### 3. Режим чтения — первый приоритет

- Крупный читаемый текст, удобная ширина строки и аккуратные отступы.
- Сворачивание боковых панелей с сохранением места чтения и результатов поиска.
- Проверка длинных статей, узкого окна и увеличенного масштаба.

### 4. Объяснение расчёта — первый приоритет

- Показать вклад выбранных статей и частей в итог, применённые ограничения
  и основания; неоднозначные сочетания обозначать явно.
- Отмена последнего действия с восстановлением предыдущего состояния.
- Выбор частей, удаление позиций, общий расчёт для двух окон и его сохранение
  уже работают; новая задача — объяснение результата и отмена.

### 5. Личные подборки и заметки

- Именованные подборки, например «Часто использую» и «Спорные моменты».
- Личные заметки к статьям и быстрый доступ к подборкам в оверлее.
- Сохранять связи при обновлении базы и переносе данных.
- Простое избранное уже есть; подборки расширяют его возможности.

### 6. Обновление базы с просмотром изменений

- До применения показать добавленные, удалённые и изменённые статьи.
- Сохранять рабочую базу, личные данные и локальные правки; конфликты показать
  пользователю до замены, предоставить возврат к предыдущей версии.
- Проверка форума в alpha только читает данные. Получение и применение
  обновлений остаются отдельной незавершённой задачей.

### 7. Восстановление рабочего состояния

- После запуска вернуть открытую статью, место чтения, расчёт и расположение окон.
- Учесть изменение мониторов и масштаба: окна должны оставаться доступными.
- Настройки, избранное, история и расчёт частично сохраняются уже сейчас;
  необходимо проверить полноту восстановления и добавить недостающее.

### 8. Быстрый возврат к предыдущей статье

Переключение между двумя последними статьями одной клавишей, без повторного
поиска и пролистывания истории. Сохранять место чтения каждой статьи.

### 9. Сравнение двух статей

Открыть статьи рядом в основном окне и независимо прокручивать; полезно при
похожих формулировках и разных кодексах. Номер и документ видны для каждой.

### 10. Понятные результаты поиска

Подсветка найденных слов в тексте, короткий фрагмент с совпадением в списке
результатов и личные сокращения для частых запросов.

### 11. Варианты копирования

Только номер и название, полный текст либо выбранный фрагмент со ссылкой на
источник. Выбор запоминается; исходный текст статьи не изменяется.

### 12. Закреплённый оверлей, пропускающий клики

Текст остаётся видимым, мышь управляет игрой. Отдельная клавиша обязательно
возвращает управление панелью; режим включается явно и имеет заметное
обозначение. Проверить выход из режима на Windows.

### 13. Перенос личных настроек одним файлом

Подборки, заметки, оформление и настройки оверлея экспортируются вместе.
Перед импортом есть просмотр содержимого и выбор объединения либо замены
с резервной копией.

Рекомендуемый порядок первых задач: пункты 1, 3, 4; затем 2, 7, 5;
после этого 6. Очередность пунктов 8–13, сроки и состав конкретного выпуска
пока не согласованы.

## Новые предложения для обсуждения — третья подборка

Эти идеи записаны отдельно. Пользователь ещё не выбирал их для реализации.

1. **Несколько черновиков расчёта.** Сохранять расчёты под своими названиями
   и переключаться между ними, не смешивая выбранные статьи. У каждого черновика
   собственный итог; активный черновик явно виден в основном окне и оверлее.
2. **Переходы по ссылкам внутри статей.** Если текст отсылает к другой статье,
   открывать её нажатием, с возвратом к прежнему месту. Неоднозначные ссылки
   показывать как выбор, а не подставлять предполагаемую статью молча.
3. **Поиск при неправильной раскладке.** Предлагать результаты для запроса,
   набранного в английской раскладке вместо русской и наоборот. Показывать
   использованное преобразование, сохраняя исходный запрос пользователя.
4. **Тихий режим во время игры.** По явному переключателю откладывать сообщения
   об обновлениях и служебные уведомления до возвращения в основное окно;
   не перехватывать управление игрой и не запускать тяжёлые фоновые операции.
5. **Автоматические резервные копии с восстановлением из интерфейса.** Сохранять
   базу и личные настройки по расписанию и перед существенными изменениями.
   В окне восстановления показывать дату и содержимое копии; перед восстановлением
   сохранять текущее состояние. Количество копий ограничивать понятной настройкой.
6. **Дата и источник редакции статьи.** Показывать происхождение текста,
   известную дату редакции и отметку о локальной правке. Отдельно отображать
   последнюю успешную проверку обновлений; не выдавать дату проверки за дату
   изменения статьи и не объявлять базу актуальной при неудачной проверке.

## Технические задачи из действующего плана

- Постепенно заменить оставшийся старый байткод исходным кодом с проверкой
  совместимости поведения. Полное восстановление прежних исходников не обещать.
- Хранить редактируемый проект и историю изменений в GitHub; выпуск Windows
  должен воспроизводиться из конкретной версии. Наличие ZIP с программой
  в GitHub само по себе не означает, что весь проект уже опубликован.
- Перед следующим выпуском проверить Windows с игрой: клавиши, фокус,
  масштабирование и несколько мониторов; измерить запуск и время поиска.
